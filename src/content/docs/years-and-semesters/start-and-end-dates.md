To set the start or end date of a semester, go to the Years page and click the name of one of your semesters.

![Clicking to edit a semester](../../../assets/edit-semester-click.png)

Then, you can edit the start and end date! Be sure to click save after you're done!

![Editing semester end date](../../../assets/edit-semester-end-date.png)
