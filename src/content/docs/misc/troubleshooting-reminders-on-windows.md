Are your reminders not working? Here are some common things to check if you're using Power Planner on Windows.

1. Did you check that Action Center's **Focus Assist is turned off**?
1. Did you check that **Power Planner's notifications are enabled in system settings**?
1. Did you check that **Power Planner's reminders are enabled within Power Planner's settings**?
