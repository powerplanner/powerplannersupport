The Windows and Android apps will send you automatic reminders for your class schedule. You can configure the reminder to be between 0-60 minutes before your class starts.

![Configuring schedule reminders](../../../assets/schedule-reminders.png)

The iOS app does not support reminders for classes yet (only for tasks/events). If you want that, [contact me](/faq/contact-support/)!
